**Live site:** https://liveprofile-eta.vercel.app/

## What's on the site

- **Projects:** Huddl and AREIVA, two full-stack platforms, plus two front-end demos, Silver Crest Estates and Lil Fish Community Center
- **Skills:** software engineering, cybersecurity, data analytics and developer tools
- **Links:** my LinkedIn and GitHub profiles and every live project
